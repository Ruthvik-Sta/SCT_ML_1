# House Price Prediction using Machine Learning

## Overview
This project predicts house prices using Machine Learning models trained on the Kaggle House Prices dataset.

The application is built using:
- Python
- Scikit-learn
- Streamlit

## Features
- Interactive house price prediction
- Machine Learning model comparison
- Streamlit web application
- Data preprocessing and feature engineering

## Dataset
Kaggle House Prices Dataset:
https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques

## ML Models Used
- Linear Regression
- Random Forest Regressor

## Selected Features
- Overall Quality
- Living Area
- Garage Capacity
- Garage Area
- Basement Area
- Full Bathrooms
- Year Built

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score

## Installation
