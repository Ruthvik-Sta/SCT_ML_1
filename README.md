# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview

This project predicts house prices using Machine Learning models trained on the Kaggle House Prices dataset.

The application is deployed as an interactive Streamlit web app where users can input house-related features and receive predicted house prices instantly.

## 📂 Dataset

Dataset used:
Kaggle House Prices - Advanced Regression Techniques

https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques

---

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
- Joblib

---

## 🤖 Machine Learning Models

The following regression models were trained and evaluated:

1. Linear Regression
2. Random Forest Regressor

Random Forest produced better prediction performance and was selected for deployment.

---

## 📊 Features Used

The model was trained using important housing features including:

- Overall Quality
- Ground Living Area
- Garage Capacity
- Garage Area
- Basement Area
- Full Bathrooms
- Year Built

---

## 📈 Evaluation Metrics

The following metrics were used for evaluation:

- MAE (Mean Absolute Error)
- MSE (Mean Squared Error)
- RMSE (Root Mean Squared Error)
- R² Score
